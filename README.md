# Introdução à Programação - FURB

Repositório contendo exercícios e atividades desenvolvidas durante a disciplina de **Introdução à Programação** do curso de **Ciência da Computação** da Universidade Regional de Blumenau (FURB).

## 📚 Sobre o repositório

Este repositório foi criado para armazenar exercícios, práticas e exemplos de código desenvolvidos ao longo das aulas da disciplina.
O objetivo é acompanhar a evolução no aprendizado de lógica de programação e desenvolvimento de algoritmos.

A disciplina faz parte da formação inicial do curso de Ciência da Computação da FURB, que busca desenvolver fundamentos sólidos em computação, raciocínio lógico e desenvolvimento de software. ([FURB][1])

## 🧠 Conteúdos abordados

Durante a disciplina são trabalhados conceitos fundamentais de programação, como:

* Lógica de programação
* Algoritmos
* Estruturas de decisão
* Estruturas de repetição
* Variáveis e tipos de dados
* Entrada e saída de dados
* Resolução de problemas computacionais

Os exercícios foram implementados principalmente utilizando **Java**.

## 🎯 Objetivo

* Praticar lógica de programação
* Desenvolver pensamento computacional
* Aprender os fundamentos da programação
* Registrar a evolução durante a disciplina
